# Встановлення як розширення браузера (без Tampermonkey)

Розширення використовує **той самий `salesdrive.user.js`**, що й Tampermonkey —
жодних розбіжностей у функціях. Файли збірки: `manifest.json`, `gm-shim.js`,
`background.js` + сам `salesdrive.user.js`.

## Установка (Chrome / Edge / Opera)

1. Завантаж папку з файлами (архів `salesdrive-extension.zip` або
   «Code → Download ZIP» з GitHub) і розпакуй у постійне місце,
   напр. `C:\salesdrive-extension\` (папку не видаляти — розширення читає її).
2. Відкрий `chrome://extensions` (в Edge — `edge://extensions`).
3. Увімкни **«Режим розробника»** (перемикач угорі праворуч).
4. Натисни **«Завантажити розпаковане» (Load unpacked)** → вкажи розпаковану папку.
5. Онови сторінку SalesDrive — все працює: банери, каса 💰, «➕ Самовивіз» тощо.

## ⚠️ Обовʼязково: вимкни Tampermonkey-скрипт на цьому ПК

Якщо лишити обидва — модулі працюватимуть **двічі** (подвійні банери, конфлікти
автопідстановок). У Tampermonkey просто вимкни скрипт перемикачем.

## Оновлення

Розширення, встановлене «розпакованим», **не оновлюється саме**:
заміни файли в папці на свіжі з GitHub і натисни ↻ на картці розширення
в `chrome://extensions`.

Для повністю автоматичних оновлень наступний крок — публікація в
Chrome Web Store як **unlisted** (прихований лінк): установка в 1 клік,
оновлення самі приходять усім. Потрібен акаунт розробника Google ($5 разово).

## Дані та кеші

Сховище розширення — `localStorage` домену salesdrive.me (префікс `lkgm_`).
Кеші таблиць/наборів відбудуються самі. Локальний журнал коригувань каси
з Tampermonkey **не переноситься** (почнеться заново; коригування з сервера
підтягнуться з позначкою «інший ПК»).

## Firefox
