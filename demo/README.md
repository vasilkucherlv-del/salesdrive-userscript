# ДЕМО-версія userscript (локальна установка)

`salesdrive.demo.user.js` — копія тестової версії для перевірки на своєму комп'ютері.

## Чим відрізняється від робочої
- Інша назва і namespace → Tampermonkey бачить її як ОКРЕМИЙ скрипт, а не як оновлення.
  Робоча версія лишається на місці й працює як раніше.
- **Автооновлення вимкнено** (немає `@updateURL` / `@downloadURL`) — файл не перезапишеться
  версією з GitHub. Оновлюється лише вручну, новим файлом.

## Як поставити
1. Значок Tampermonkey → «Створити новий скрипт».
2. Виділити весь вміст вікна (Ctrl+A) і видалити.
3. Вставити вміст `salesdrive.demo.user.js` (Ctrl+V) → Ctrl+S.
3'. Або: Tampermonkey → «Утиліти» → «Імпорт з файлу» → вибрати файл.
4. Відкрити СРМ і перезавантажити сторінку (Ctrl+F5).

## Важливо: дві копії одночасно
Робоча і демо стартують разом, тому одна з них сама зупиниться і напише в консоль
(F12) «[SD] інша копія скрипта … зупинено». Це нормально і зроблено навмисно, щоб
банери не дублювалися. Щоб перевіряти саме демо — тимчасово вимкніть робочу
(перемикач у списку скриптів Tampermonkey).

## Як прибрати
Tampermonkey → список скриптів → «SalesDrive … (ДЕМО …)» → видалити.
